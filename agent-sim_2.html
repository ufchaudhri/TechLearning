Module 3
Agent Handoffs via Kafka
Agents don't call each other directly — they publish typed artefacts to Kafka topics. Click each agent to trigger it, watch the packet travel to the next, and approve the gate to unlock the next phase.
📨
Handoff Event
adlc.handoff event payload Avro/JSON

Why Kafka instead of direct HTTP?

⚠
HTTP problem: If WIRE-AGENT is restarting when REQ-AGENT finishes, a direct POST /run call fails. Completed work is lost. REQ-AGENT would need retry logic, timeouts, and circuit breakers — all coupling the agents tightly.
✓
Kafka solution: REQ-AGENT publishes to adlc.handoff.req-to-wire and its job is done. The event persists in the topic until WIRE-AGENT is healthy. No coupling, no lost work, full replay capability.
